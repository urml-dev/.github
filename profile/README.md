**URML is the standard language for robot intent.** Say what a robot should do in plain English. URML turns it into a typed program, checks it against the robot's capabilities, its safety envelope and the law, then runs it on ROS 2, PX4, ArduPilot, OPC UA, AUTOSAR, Isaac Sim, MuJoCo and more.
